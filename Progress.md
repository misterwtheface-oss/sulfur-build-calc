## Known issues / warnings
- **Data-vs-runtime overrides.** Some weapons are overridden in code (e.g. Augusta forced to
  3 pellets; `weapons.csv` shows 1). P0 uses the datamined CSV value. A curated overrides layer
  may be needed for exact runtime parity — see PROCEDURAL_MAP §6.
- **GlobalDamageMultiplier** is treated as a pooled fractional bonus around 0 in P0; confirm the
  attribute's true base/scaling against `Weapon.GetDamage` if any enchant grants it.
- **Enchant applicability.** P0 lists all 314 enchantments as weapon-applicable; some are armor/
  consumable enchants. P1 should gate by apply-context/slot.
- Player class/element `ExtraDamage_*` and headshots are NOT yet in the damage headline (ledger only).
