# SULFUR extracted data tables

Generated by `build_tables.py` from datamined Unity ScriptableObject YAML assets under
`_unityproject/ExportedProject/Assets/_Core/GameDefinitions/`. Read-only extraction; re-runnable.

## CAVEATS

- **Extract, not golden.** Values are pulled directly from the game's serialized assets. Enum
  decoding is derived from the DECOMPILED C# under `code/`; if the game's enum ordering differs
  from the decompile, decoded `_name` columns could be wrong. Raw int columns are always kept alongside.
- Enum fields serialize as raw ints in Unity YAML; `<field>_name` columns are the decoded values.
- `itemTags` is a bitflag enum (`Organ=1`, `Valuable=2`); `itemTags_name` is the OR-decoded set joined by `|`.
- Parsing is a tolerant hand-written Unity-YAML walker (PyYAML chokes on `!u!` tags). A malformed
  asset is skipped and reported below rather than aborting the run.

## Files & columns

### weapons.csv
All WeaponSO assets. `caliber` (raw ordinal) is joined to the Calibers assets to pull
`caliber_baseDamage` and `pellets`. `computed_base_damage = caliber_baseDamage * damageMultiplier`.
`shot_interval_s = 60 / rpm`. Columns: name, displayName, itemQuality, itemQuality_name, weaponType, weaponType_name, caliber, caliber_name, caliber_baseDamage, pellets, damageMultiplier, computed_base_damage, rpm, shot_interval_s, iAmmoMax, fReloadTime, weightClass, weightClass_name, basePrice, damageType, damageType_name, bulletSpeed, shotsToReachFullSpread, iMaxAmmoPerShot, adsEnabled, category.

### items.csv
Every ItemDefinition across all `Items/` categories (weapons included, with their item-level
fields). `category` is the relative folder path under `Items/`. Modifier lists are flattened
to `attr=value(modType)` joined by `;`. Columns: name, category, id, displayName, description, flavor, itemQuality, itemQuality_name, slotType, slotType_name, itemTags, itemTags_name, useType, useType_name, weightClass, weightClass_name, basePrice, sellable, stackSize, inventorySize, maxDurability, appliesEnchantment, modifiesCaliber, modifiersOnEquip, modifiersOnInventory, baseAttributes.

### enchantments.csv
One row per EnchantmentDefinition (whole `Enchantments/` subtree). `modifiersApplied` flattened
to `attr=value(modType)` joined by `;`. Columns: name, id, enchantmentName, IsElemental, CostsDurability, modifiersApplied, category.

### loot_tables.csv
One row per (table, entry). LootTable ScriptableObjects only (m_Script fileID -1821684959); loot-spawner components inside prefabs are excluded. `drop_pct = weight /
sum(weights in that table) * 100`. `entry_kind` is `item` (direct drop; `item` column resolved
via guid) or `import` (references another loot table by guid). Columns: table, entry_kind, item, weight, drop_pct, table_total_weight, category.

### cards.csv
Roguelike upgrade cards (m_Script fileID -1589123477, under `Assets/MonoBehaviour/`).
Columns: name, cardKey, displayName, description, cardType, buffType, buffAmount, rewardType, preselectionChance.
